# 霓虹 GIF 生成器 (Neon GIF Generator)

这是一个基于 Python FastAPI 的超级 GIF 生成平台，专注于生成酷炫的赛博朋克文字 GIF、动态特效文字以及带有沉浸式视频遮罩的文字动画。

项目内置了现代化的 Web 界面，完美实现“所见即所得”，并在后端提供了极为丰富且高度灵活的生成参数，让用户可定制出独具一格的动画 GIF。

## ✨ 核心特色与特效大全

### 🌟 1. 动态排版特效 (Dynamic Text Effects)
无需任何背景，文字本身具备丰富动效：
*   🌈 **彩虹流动 (Rainbow Flow)**：动态流动的彩虹渐变。
*   🌊 **波浪 (Wave)**：文字像波浪一样上下起伏，可自由指定颜色（也可选择彩虹色）。

*   💡 **霓虹脉冲 (Neon Pulse)**：模拟霓虹灯的闪烁和发光效果。
*   ⚡ **故障风 (Glitch)**：赛博朋克风格的信号干扰和画面撕裂效果。

*   🌋 **剧烈抖动 (Extreme Shake)**：每个字符完全独立、不规律地上下左右剧烈抖动。
*   💗 **心跳缩放 (Zoom)**：文字像心脏一样在中心有节奏地放大缩小。
*   💨 **滑动缩放 (Zoom Slide)**：文字如跑马灯般从右向左滑入，同时到达中心时放大，离开时缩小。
*   🎯 **飞字缩放 (Fly Zoom)**：中间最多3个字符逐字放大占据满屏，两侧带有倾斜的文字如流星般飘过。
*   💥 **喷发 (Spray)**：文字从中心向四周喷飞发散。
*   📜 **滚动 (Scroll) / 跑马灯 (Marquee)**：文字平滑滚动的展示效果。
*   ✨ **闪耀 (Shining)**：文字上掠过高光闪耀效果。
*   ⌨️ **打字机 (Typewriter)**：模拟逐字敲击的打字动画。
*   🌫️ **溶解 (Dissolve)**：文字像沙漏一样消散褪去。
*   🌬️ **呼吸灯 (Breathing)**：纯色或双色渐变的呼吸明暗交替。
*   🎈 **漂浮字 (Floating Text)**：3D立体文字配以描边阴影从底部向上缓缓漂浮，伴随着飘落的美丽雪花与爱心。

*   🌀 **螺旋3D旋转 (Spiral 3D)**：极致3D纵深特效。每个字符被赋予不同的字体，沿圆柱螺旋轨迹360°旋转上升，在远近交替间实现缩放与透明度变化。

## 🚀 快速开始

### 1. 环境要求
*   Python 3.8+
*   依赖库：`fastapi`, `uvicorn`, `pillow`

### 2. 安装依赖
```bash
pip install -r requirements.txt
```

### 3. 启动服务
```bash
python main.py
```
*(或者使用 `uvicorn main:app --reload` 以启用热更新)*

默认监听 `http://127.0.0.1:8066/`。当前实现会对预览请求自动限帧、限制预览画布尺寸，并缓存重复生成结果，以减少等待时间和 CPU/内存占用。

### 4. 使用 Web 界面
服务启动后，直接在浏览器中打开：
**http://127.0.0.1:8066/**
即可在下拉菜单中直接选择各种酷炫特效并一键生成。

### 5. Docker 部署 (推荐)
本项目已完美配置 Docker 支持，包含所有必要的系统库（尤其对中文字体做了完整映射和支持）。
在根目录下直接运行：
```bash
docker-compose up -d --build
```
等待构建完成后，访问 **http://[你的服务器IP]:8066** 即可。

## 📖 API 使用说明

如果你想将生成器对接到自己的机器人、小程序或后端服务，可直接调用 `/generate` 接口。

**示例请求:**
```
http://127.0.0.1:8066/generate?text=Hello&color=cute_streamer_mask&theme=transparent&width_pixels=500&frame_count=30
```

**核心参数:**
| 参数 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `text` | string | (必填) | 要生成的文字内容，支持中文、Emoji和标点 |
| `color` | string | None | 极重要的核心参数！可以传普通的 Hex 颜色(`FF0000`)，也可以直接传**各种特效的代号**(如 `zoom_slide`, `fly_zoom`, `wave`, `cute_streamer_mask`, `matrix` 等) |
| `theme` | string | transparent | 背景主题颜色: `transparent`(透明底), `dark`(深色底), `light`(浅色底) |
| `width_pixels` | int | 500 | 限制生成 GIF 的最大参考宽度 |
| `frame_count` | int | 20 | 动画总帧数。纯文字特效会自动使用更轻的帧数上限，优先缩短生成等待时间 |
| `delay` | int | 100 | 每两帧之间的间隔 (ms)，越小越顺滑 |
| `adaptive_canvas` | bool | false | 自适应画布。纯文字特效默认启用，透明背景不再固定 480x480，而是根据字数和文字边界放大或缩小 |
| `preview` | bool | false | 快速预览模式。会降低预览帧数和画布上限，适合用户输入后即时刷新 |

## 🎨 字体引擎
本系统内置了一套智能随机加载引擎，服务启动时将从 `fonts/` 文件夹中自动加载 `.ttf`、`.otf` 格式的字体。所有特效及模板都会自动适配到该字体，为防止视觉疲劳增强每次生成的独特性。
